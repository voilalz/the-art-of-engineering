# 工程概念辨析

这个入口用于解决工程讨论中“词相同、含义不同”或“几个指标被当成同一件事”的问题。每个主题同时回答：它描述什么、怎样量化、前提是什么、与邻近概念有什么关系，以及会改变哪项工程决策。

## 已有主题

| 遇到的问题 | 先分开什么 | 详细说明 |
| --- | --- | --- |
| 精度、误差、分辨率到底是什么关系 | 准确度、正确度、精密度、误差、不确定度与分辨率 | [测量性能概念](measurement-performance.md) |
| 灵敏度高是好事还是坏事，为什么控制系统又要求低灵敏度 | 测量转换斜率、参数敏感程度、反馈灵敏度函数 | [系统灵敏度](sensitivity.md) |

这些主题服务于选型、接口、误差预算、试验和验收。可结合[能力框架](../engineering-framework.md)、[误差预算案例](../../examples/error-budget.md)与[任务记录模板](../../templates/engineering-task.md)使用。

## 阅读时先问五件事

1. **对象是什么：** 单次测量、一组重复结果、某个部件，还是整机？
2. **谁相对于谁变化：** 测量值与参考值，输出与输入，还是性能与参数？
3. **量化口径是什么：** 边界、标准差、分位值、偏导数或传递函数？
4. **条件是什么：** 工作点、环境、频率、带宽、采样、统计模型与配置？
5. **工程后果是什么：** 会改变选型、标定、分配、试验还是判据？

“精度 0.1”“灵敏度高”“系统稳定”都需要继续落实到这些问题，才能变成可计算、可验证的技术要求。

## 后续待辨析的问题

下表记录后续问题，当前未视为已完成文档。

| 概念组 | 要解决的混淆 |
| --- | --- |
| 标准差、RMS、RMSE、最大误差、分位值 | 统计口径不同，何时可以换算 |
| 随机噪声、偏差、漂移、迟滞 | 不同来源怎样识别、补偿与进入预算 |
| 重复性、再现性、批次一致性 | 重复测一台与跨设备、跨条件验证有什么不同 |
| 标定、调整、修正、验证 | 建立关系、改变设备和确认要求分别做什么 |
| 采样率、带宽、响应时间、时延、抖动 | 更新得快是否代表测得快、控得快 |
| 稳定性、鲁棒性、可靠性、可用性 | 动态不发散、参数变化可承受与长期可用分别怎样判断 |
| 公差、最大允许误差、不确定度、设计余量 | 要求、测量证据和预留空间怎样区分 |
| 可观测性、可辨识性、灵敏度 | 对变化有响应，是否就能知道状态或辨识参数 |

新增辨析时，保留反例、计算条件、工程用法和主要来源；不将某个专业中的局部定义直接推广到所有语境。
