# 术语约定

本页规定全库反复出现、又容易在中文里混用的词怎样使用。各章可以在本地给出更严格的定义，但不应与这里冲突。概念背后的完整辨析见[概念辨析](concepts/README.md)。

## 依据与优先顺序

1. 计量术语：VIM 第 3 版（JCGM 200:2012），中文译名对照 JJF 1001—2011《通用计量术语及定义》。
2. 不确定度：JCGM 100:2008（GUM），中文对照 JJF 1059.1—2012。
3. 准确度、正确度、精密度及重复性、再现性条件：ISO 5725-1（GB/T 6379.1）。
4. 系统工程过程与术语：ISO/IEC/IEEE 15288:2023（国标 GB/T 22032 等同采用其早期版本），要求工程：ISO/IEC/IEEE 29148:2018，并参照 NASA 系统工程手册。
5. 可靠性与故障术语：IEC 60050-192（国际电工词汇，可信性）。
6. 功能安全术语：IEC 61508-4。

项目内的工作约定会注明“本库约定”，不冒充标准原文。

## 用词对照

| 本库用词 | 英文 | 本库含义 | 不要混用为 |
| --- | --- | --- | --- |
| 需要 | need | 利益相关方期待的能力、效果或要解决的问题，可以是定性的 | 已批准、可验证的条款 |
| 要求 | requirement | 经分析形成、对某个实体具有约束力、可以验证的规定 | “需求”。本库不用“需求”指规定性条款；“资源需求量”等表示需要多少资源时可以使用“需求” |
| 验证 | verification | 用客观证据证明满足规定要求（做得对不对） | 确认 |
| 确认 | validation | 用客观证据证明在预期环境中满足预期用途（做的是不是对的东西） | 验证 |
| 误差 | error | 测得值（或输出）减去参考值，有符号 | 不确定度、允许误差 |
| 偏差（测量偏差） | bias | 系统测量误差的估计值；JJF 1001 译作“测量偏移”，首次出现时注明 bias。尺寸语境写全称“尺寸偏差”“上/下极限偏差”（GB/T 1800.1），不单写“偏差” | 跟踪误差、单次误差、尺寸偏差 |
| 测量不确定度 | measurement uncertainty | 依据所用信息，表征赋予被测量的量值分散性的非负参数；A类、B类是评定途径，不等同于随机、系统误差 | 误差、允许误差 |
| 覆盖区间、覆盖因子 | coverage interval, coverage factor | 以规定概率包含一个被测量量值的区间，及扩展不确定度中的乘数 $k$；JJF 1001 译作“包含区间”“包含因子” | 置信区间 |
| 置信区间 | confidence interval | 在重复抽样意义下以规定置信度覆盖总体参数（均值、标准差等）的区间 | 单次结果的范围 |
| 统计容忍区间 | statistical tolerance interval | 以规定置信度包含总体中至少规定比例的区间（ISO 16269-6，GB/T 3359） | 公差、置信区间 |
| 跟踪误差 | tracking error | 实际状态或输出相对期望/指令值之差，常见于控制和运动 | 测量误差 |
| 残差 | residual | 观测值减去模型预测或拟合值 | 误差（残差依赖所用模型） |
| 精度 | — | 口语用法，不作为正式指标名称；正式文件写明准确度、精密度、误差界或具体统计量 | 单一数值指标 |
| 公差 | tolerance | 规定的允许变动范围，属于设计要求 | 不确定度、误差 |
| 最大允许误差 | MPE | 规范或规程对误差规定的极限值 | 实测误差、标准差 |
| 余量（设计余量、性能余量） | margin | 能力减去需求后为明确目的保留的空间，需写明定义和由谁持有 | 裕度、安全系数 |
| 预留量 | reserve | 系统层保留、尚未分配给任何下级的量，由系统层持有，按记录的决定释放 | 余量 |
| 稳定裕度 | stability margin | 反馈系统距离失稳的程度，如增益裕度、相位裕度、模值裕度 | 余量 |
| 安全系数 | safety factor | 规范或行业依据规定的乘数，用于覆盖未单独建模的影响 | 余量、误差包络 |
| 故障 | fault | 部件或设计中能够导致错误的缺陷或异常状态（原因） | 失效 |
| 错误 | error（可信性语境） | 由故障激活后，系统内部状态偏离正确状态 | 测量误差 |
| 失效 | failure | 系统或部件不再能按要求提供功能（对外表现的事件） | 故障 |
| 危险 | hazard | 可能导致伤害的潜在来源 | 风险 |
| 风险 | risk | 伤害或不利后果的发生可能性与严重程度的组合 | 危险 |

“错误”在计量语境中指测量误差，在可信性语境中指内部错误状态，两者以所在章节和英文注明区分。“模型失效”“方法失效”等用法表示“不再适用”，保留日常含义。

## 写作规则

- 正式条目中出现“精度”“稳定”“可靠”“灵敏度高”等词时，在同一句或紧随其后写明具体量、条件和判据。
- 首次出现上表中容易混淆的词时附英文；同一文档内保持同一译名。
- 余量必须说明计算式、所对应的工况和持有方，避免多个团队重复使用同一预留量。
- 引用标准时写明编号和年份；被引用标准修订后，复核受影响的定义。
