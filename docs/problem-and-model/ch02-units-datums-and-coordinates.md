# 第2章 单位、基准与坐标：工程的共同语言

**所属主题：问题与模型｜版本：V0.1 研究正文初稿｜日期：2026-11-15**

## 2.1 数据交换需要保持什么

两个团队都可能正确完成各自的计算，却在连接后得到错误结果：一边输出毫米，另一边按米使用；一边报告相对安装面的距离，另一边理解为相对设备原点的位置；一边输出相对平台的速度，另一边当成相对地面的速度；一边记录采样时刻，另一边按数据到达时刻对齐。

这些问题的共同点，是接口传递了数值，却没有完整传递数值所描述的物理关系。第一章建立任务和要求的含义；本章进一步规定物理量怎样表达、参考如何定义、变换需要哪些条件，以及怎样检查跨模块解释的一致性。

本章的核心原则是：**每次转换都应说明保留了什么物理关系、改变了什么表达，以及需要哪些附加信息。**

| 操作 | 保持或重新确定的内容 | 需要的信息 |
| --- | --- | --- |
| 同种量的单位表达变换 | 同一量值，数值和单位表达改变 | 单位及转换因子 |
| 参考零点变换 | 同一物理状态或位置，参考读数改变 | 零点、参考值及其状态 |
| 同一向量的坐标表达变换 | 同一个物理向量，分量改变 | 坐标轴关系 |
| 同一点的位置坐标变换 | 同一物理点，原点和轴向表达改变 | 原点位置、轴向关系及对应时刻 |
| 改变测点或运动参考 | 关注的物理关系发生改变 | 几何、相对运动或其他关联模型 |
| 改变统计表征 | 从同一过程提取另一种描述 | 波形、时间窗、带宽及处理定义 |

这些操作可能组合出现，但不应混成一个含义不明的“转换函数”。本章采用经典力学、欧氏空间和共同物理时间的工程模型；所列数值均为教学示例。

## 2.2 量、单位与量纲：保持简明但准确的约定

### 2.2.1 基本术语

以下中文释义参照SI手册和VIM。[R1—R4]

| 术语 | 本章采用的含义 | 应避免的混淆 |
| --- | --- | --- |
| 量 quantity | 可以用数和参考表达大小的现象、物体或物质的属性 | 数值本身不是完整物理量定义 |
| 量的种类 kind of quantity | 可相互比较的量所具有的共同方面，如长度、能量 | 同量纲不自动意味着同种量 |
| 量值 quantity value | 共同表达量的大小的数与参考 | 参考通常是单位，也可能涉及规定程序或材料 |
| 数值 numerical value | 在所选单位等参考下，量值表达中的数 | 改单位时数值可以改变 |
| 测量单位 measurement unit | 按约定定义和采用、用于与同种量比较的实标量量 | 单位名称不能独自完整说明所测对象 |
| 量纲 quantity dimension | 用基本量量纲的幂积表达量的依赖关系，并略去数值因子 | 量纲不编码对象、参考系或标量/向量性质 |

对能够以单位乘积表达的标量量值，采用：

$$
Q=\{Q\}_u\,u,\qquad \{Q\}_u=Q/u.
\tag{2-1}
$$

u为选定单位，$\{Q\}_u$为该单位下的数值。对于向量或张量，分量各有相应量值。式（2-1）不把所有程序定义量都强行归为同一种乘积表达。

在国际量制常用基本量下，量纲一般写作：

$$
\dim Q=\mathsf L^\alpha\mathsf M^\beta\mathsf T^\gamma
\mathsf I^\delta\mathsf\Theta^\varepsilon
\mathsf N^\zeta\mathsf J^\eta.
\tag{2-2}
$$

这里的符号依次表示长度、质量、时间、电流、热力学温度、物质的量和发光强度的量纲，不是变量数值，也不等同于单位符号。[R2]

量纲检查是必要的关系检查。例如力矩和能量具有相同量纲，但不是同种量。[R1][R2] 对周期为 $T_p$的同一过程，频率 $f=1/T_p$，角频率 $\omega=2\pi/T_p=2\pi f$；1 Hz对应角频率 $2\pi$ rad/s。这里的 $2\pi$来自两种量的定义，不能与同一平面角的度—弧度单位变换混为一谈。“无量纲”同样不意味着没有角度、比例、计数等物理语义。

### 2.2.2 单位缩放与参考零点应分别处理

若同一量采用单位 $u_1$ 和 $u_2$，且 $u_1=k u_2$，则：

$$
\{Q\}_{u_2}=k\{Q\}_{u_1}.
\tag{2-3}
$$

例如1000 mm与1 m描述同一长度量值；30°与 $\pi/6$ rad描述同一平面角。平方、立方和复合单位中的因子也要相应变换：1 mm²等于 $10^{-6}$ m²，1 mm³等于 $10^{-9}$ m³。

不能把所有温标、标尺和参考表达都当作式（2-3）的纯比例变换。对热力学温度T和摄氏温度t，SI规定：[R1]

$$
\frac{T}{\mathrm K}=\frac{t}{{}^\circ\mathrm C}+273.15,
\qquad
\frac{\Delta T}{\mathrm K}=\frac{\Delta t}{{}^\circ\mathrm C}.
\tag{2-4}
$$

T与t是以不同参考零点建立的温度量表达，温差的单位大小相同。20 ℃对应293.15 K；升高20 ℃则对应升高20 K。不能从“30 ℃是15 ℃的两倍”推断热力学温度倍增。

本章在写仿射数值关系 $x_2=a x_1+b$ 时，$x_1,x_2$表示已明确单位和参考的数值。a、b的含义由具体转换定义；不能仅凭这个形式，就把单位、标定、零点或物理模型视作同一种操作。

## 2.3 “绝对”“相对”与不同领域的参考

### 2.3.1 用具体定义替代含糊词语

“绝对”和“相对”需要与具体量共同解释。令x为测得的量值、$x_{\mathrm{ref}}$为对应的参考量值，二者应针对同一被测量及规定条件，并统一单位和基准。本章将有符号测量误差记为 $e=x-x_{\mathrm{ref}}$，误差大小记为 $|e|$；参考量值也可能具有测量不确定度，不能自动当作已知真值。若采用相对误差，则明确定义：[R5]

$$
e_{\mathrm{rel}}=\frac{x-x_{\mathrm{ref}}}{x_{\mathrm{ref}}},
\qquad x_{\mathrm{ref}}\neq0.
\tag{2-5}
$$

不同资料中“绝对误差”有时指未经归一化的差，有时指误差的绝对值，引用时应说明用法。参考值接近零时，相对误差可能不适合，应选用有依据的固定尺度或其他指标。

百分数也需要说明分母。教学例中，若测量范围为0—100 mm、当前读数10 mm，则1%读数对应0.1 mm，而1%量程跨度对应1 mm。实际资料中的满量程可能采用跨度、端点或其他定义，应查明后使用。

### 2.3.2 机械基准：理想参考与实际实现

机械基准用于建立位置、方向及几何关系的参考。在几何公差语境下，它通常是按规定方法由基准要素建立的理论准确参考，如点、直线、平面或其组合。应区分这种理想参考与用于建立它的实际基准要素，例如某个真实表面、孔或接触区域。实际要素和装夹、探测、拟合过程可能影响基准的实现。

NIST关于基准系统的数据模型研究明确区分datum、datum feature及相关关系。[R6] 具体几何产品规范或GD&T术语应采用项目选定的规范及版本；本章不将某一历史规范的定义直接作为所有图纸的统一规则。

数据字典至少应说明：基准由哪个要素建立，采用何种建立或拟合方式，原点和轴向怎样确定，工件如何装夹，变更后怎样重建。理想坐标关系可以精确规定，实际基准的实现仍可能存在不确定度。

### 2.3.3 压力参考：绝对压力、表压和差压

压力表达必须说明参考。绝对压力以理想真空为零参考；表压相对仪器规定的参考压力，差压表示规定两端压力之差。对以当地大气压为参考的通气表压，有：[R7]

$$
p_g=p_{\mathrm{abs}}-p_{\mathrm{atm}},
\qquad
\Delta p=p_1-p_2.
\tag{2-6}
$$

其中 $p_{\mathrm{abs}}$为绝对压力，$p_{\mathrm{atm}}$为对应地点和时刻的大气压力，$p_g$为该定义下的表压。差压的两端与方向应明确；采用密封参考腔等方式的仪器，应按其实际参考定义处理。

假设某次表压为200 kPa、参考大气压力为100 kPa，则绝对压力为300 kPa。这里100 kPa是示例环境值，不是可以在所有地点和时刻固定代入的换算常数。

### 2.3.4 电气参考：电压必须有两端和方向

在适用电势差或相应集总电路电压定义的情形下，本章规定 $V_{AB}$表示A端相对B端的电压；在电势差模型中，$V_{AB}=\varphi_A-\varphi_B$，其中 $\varphi$为相应电势。采用共同参考节点G，有：[R8]

$$
V_{AB}=V_{AG}-V_{BG},\qquad
V_{AG_2}=V_{AG_1}-V_{G_2G_1}.
\tag{2-7}
$$

例如A端相对 $G_1$为5 V，$G_2$相对 $G_1$为2 V，则A相对 $G_2$为3 V。两台设备分别报告5 V和3 V可能都正确；判定前需要统一参考关系。

机壳、保护接地、模拟参考、数字参考和差分输入负端不能仅因名称中含有“地”就视为同一节点。电压正方向、电流正方向及元件功率符号应在图纸或接口中注明。对存在显著电磁感应或分布效应的情况，还需要相应电路与场模型，不能把所有电压关系只解释成一个全局标量电势差。

### 2.3.5 本章对“基准”的使用范围

“基准”在本章是帮助组织工程信息的统称。机械基准、电气参考节点、空间原点、温标零点与时间原点各有专业定义。它们共同要求参考明确，但并不意味着都能用一个相同的数学公式转换。

## 2.4 峰值、有效值与平均值：单位相同，表征不同

### 2.4.1 定义时间窗和统计操作

对实值信号x(t)，取同一个时间窗 $W=[t_0,t_0+T_w]$、$T_w>0$。假设相关积分存在且信号在窗内有界，定义：

$$
\begin{aligned}
\bar x_W&=\frac1{T_w}\int_W x(t)\,\mathrm dt,\\
x_{\mathrm{rms},W}&=\sqrt{\frac1{T_w}\int_W x^2(t)\,\mathrm dt},\\
x_{\mathrm{pk},W}&=\sup_{t\in W}|x(t)|,\\
x_{\mathrm{pp},W}&=\sup_{t\in W}x(t)-\inf_{t\in W}x(t).
\end{aligned}
\tag{2-8}
$$

本章的峰值明确指绝对幅值上界；若使用正峰值或负峰值，应另行说明。实际采样得到的峰值还受采样、带宽和仪器响应影响，不自动等于连续信号的真实峰值。

对均匀采样数据，平均值和RMS可分别用 $N^{-1}\sum x_k$、$\sqrt{N^{-1}\sum x_k^2}$计算。非均匀采样和加权处理需采用对应的时间或权重定义；RMS中的N也不能直接改成样本标准差的N-1。

有效值的一个物理解释来自恒定电阻R：若电压为v(t)，则同窗平均耗散功率为 $\bar P_W=v_{\mathrm{rms},W}^2/R$。因此，电压有效值等于在该电阻上产生同样平均耗散功率的直流电压大小。这个解释具有恒定纯电阻的条件，不能由此推断任意交流负载的有功功率都等于电压RMS与电流RMS的乘积。

### 2.4.2 波形条件决定换算关系

令 $x_{\mathrm{ac}}(t)=x(t)-\bar x_W$，由展开平方并利用同窗交流分量平均为零，可得：

$$
x_{\mathrm{rms},W}^2=\bar x_W^2+x_{\mathrm{ac,rms},W}^2.
\tag{2-9}
$$

若 $x(t)=b+A\sin(\omega t+\varphi)$、$\omega>0$，且窗口覆盖整数个周期，则平均值为b、交流RMS为 $|A|/\sqrt2$、总RMS为 $\sqrt{b^2+A^2/2}$、峰峰值为 $2|A|$。纯正弦零直流情况下才得到常用的“RMS等于峰值除以 $\sqrt2$”关系。[R9]

例如 $x(t)=\bigl(3+4\sin(\omega t)\bigr)\,\mathrm V$，在上述窗口条件下：

| 表征 | 数值 |
| --- | --- |
| 算术平均值 | 3 V |
| 交流分量RMS | $2\sqrt2\approx2.828$ V |
| 包含直流的总RMS | $\sqrt{17}\approx4.123$ V |
| 绝对峰值 | 7 V |
| 峰峰值 | 8 V |

这些量单位相同，不能未经波形和口径说明相互替代。资料中的“平均值”还可能指整流平均值，应与有符号算术平均区分；仪器的交流RMS和交流加直流RMS也应分别记录。

统计字段至少应含窗口、采样或带宽、滤波、是否包含直流、是否取绝对值及计算方法。RMS是对平方平均的表征，不要求信号必须服从某种概率分布；若将时间统计用于总体推断，则需要另外建立统计假设。


## 2.5 空间基准、坐标系与几何量

### 2.5.1 坐标系的组成与本章约定

本章的三维笛卡尔坐标系A由原点 $O_A$ 和三个正交单位基向量 $\mathbf e_x^A,\mathbf e_y^A,\mathbf e_z^A$组成。除明确说明外，采用右手正交系、列向量和共同物理时间。坐标系不因称为“世界系”或“设备系”就自动成为惯性参考系。

原点确定位置的起算点；基向量确定分量的方向；随时间运动的参考系还决定运动量和向量导数相对于谁定义。同一组轴可以用于表达不同参考关系下的量。

“前、右、下”“前、左、上”“东、北、天”等约定各有使用语境。ROS REP 103给出其项目中的机体、相机和地理坐标约定，其他行业或系统应说明自己的选择，不能凭轴名称推断全部定义。[R15]

### 2.5.2 物理向量与分量

$\mathbf r_{PQ}$表示从物理点P指向物理点Q的位移向量；$[\mathbf r_{PQ}]_E$表示它沿坐标系E各轴的分量。方括号下标只负责说明表达基。

定义 $R_{AB}$将同一向量从B轴分量转换到A轴分量：

$$
(R_{AB})_{ij}=\mathbf e_i^A\cdot\mathbf e_j^B,
\qquad
[\mathbf q]_A=R_{AB}[\mathbf q]_B.
\tag{2-10}
$$

第j列是B的第j个单位基向量沿A轴的分量。对右手正交系，有：

$$
R_{AB}^{\mathsf T}R_{AB}=I,\quad
\det R_{AB}=1,\quad
R_{BA}=R_{AB}^{\mathsf T},\quad
R_{AC}=R_{AB}R_{BC}.
\tag{2-11}
$$

因此 $R_{AB}$属于三维特殊正交群SO(3)。该方向约定与机器人学中的成熟做法相容，但接口中仍应明确写出“输入B、输出A”的等式。[R10]

### 2.5.3 点坐标与位移向量的平移规则不同

令 $\mathbf p_P^A=[\mathbf r_{O_AP}]_A$、$\mathbf p_P^B=[\mathbf r_{O_BP}]_B$，分别为同一点P在A、B中的位置坐标。再定义 $\mathbf t_{AB}=[\mathbf r_{O_AO_B}]_A$，则：

$$
\mathbf p_P^A=R_{AB}\mathbf p_P^B+\mathbf t_{AB}.
\tag{2-12}
$$

P没有改变，但位置起点和分量表达轴都可能改变。两个位置坐标一般对应从不同原点指向P的两个位置向量，不能含糊地称为“同一个向量只是换了分量”。

对两点间同一位移，平移项相消：

$$
[\mathbf r_{PQ}]_A
=\mathbf p_Q^A-\mathbf p_P^A
=R_{AB}(\mathbf p_Q^B-\mathbf p_P^B)
=R_{AB}[\mathbf r_{PQ}]_B.
\tag{2-13}
$$

若需要从传感器点P求作用点Q，还需已知 $\mathbf r_{PQ}$及其对应姿态，使用 $\mathbf p_Q^A=\mathbf p_P^A+[\mathbf r_{PQ}]_A$。这一步改变了被描述的点，不能仅由“换到A系”自动完成。

### 2.5.4 齐次变换的适用对象

可将式（2-12）写为：

$$
T_{AB}=
\begin{bmatrix}R_{AB}&\mathbf t_{AB}\\\mathbf0^{\mathsf T}&1\end{bmatrix},
\qquad
\begin{bmatrix}\mathbf p_P^A\\1\end{bmatrix}
=T_{AB}\begin{bmatrix}\mathbf p_P^B\\1\end{bmatrix}.
\tag{2-14}
$$

T的旋转块无量纲，平移块与位置采用同一长度单位。对同一位移或方向向量，齐次表示末项为0，因此平移块不参与作用。将任何三元组都补1后套入点变换，会对速度、方向等数据加入没有物理意义的平移。

对当前刚体变换，$T_{BA}=T_{AB}^{-1}$，复合顺序为 $T_{AC}=T_{AB}T_{BC}$；矩阵乘法通常不可交换。[R10] 不同时刻获得的变换还需时间一致性，不能只按下标机械拼接。

## 2.6 “相对”与“相对于”：把关系明确写出

### 2.6.1 两个中文词不天然对应两种数学操作

“相对”“相对于”“在某坐标系中”是自然语言，需要结合定义判断。不能规定“相对于一定表示坐标表达”“相对一定表示速度差”之类的一一对应关系。

| 信息 | 回答的问题 | 示例 |
| --- | --- | --- |
| 研究对象 target | 描述哪个点、物体或坐标系 | 点P、平台B、工件作用点 |
| 几何参考或比较对象 | 从哪个点出发，或与谁作差 | 从Q指向P，两点速度之差 |
| 运动或求导参考系 | 相对于哪组随时间运动的轴观察变化 | 在A中观察P的运动 |
| 表达坐标系 expressed-in frame | 结果的分量沿哪组轴给出 | 将该速度沿E轴表达 |
| 对应时刻 | 关系在哪一时刻成立 | 采样时刻、状态有效时刻 |

Drake的多体记法明确区分物理量的参考、目标与表达基，本章借鉴这种显式记录方式。[R11][R12]

### 2.6.2 点相对参考系的速度

用 $D_A\mathbf q$表示物理向量 $\mathbf q$在参考系A中、对共同时间t的导数。点P相对于A的速度及加速度定义为：

$$
{}^A\mathbf v^P:=D_A\mathbf r_{O_AP},
\qquad
{}^A\mathbf a^P:=D_A({}^A\mathbf v^P).
\tag{2-15}
$$

原点 $O_A$固定在A中。$\,{}^A\mathbf v^P$是一个物理速度向量，尚未指定用于数值表达的基。本章采用 $[{}^A\mathbf v^P]_E$表示“P相对A的速度，沿E轴表达”：左上标A是运动参考，右上标P是对象，方括号下标E是表达坐标系。

这套显式记法在本章中统一使用；其他文献可能采用不同上下标安排，阅读时应先确认定义，不能只看字母位置推断含义。

### 2.6.3 同一速度换表达基

保持对象和运动参考不变，仅从E轴分量改为F轴分量：

$$
[{}^A\mathbf v^P]_F=R_{FE}[{}^A\mathbf v^P]_E.
\tag{2-16}
$$

R是无量纲旋转矩阵，这一步不改变P相对于A的运动。不能把右式中的A同时替换成F，声称已经完成运动参考系变换。

### 2.6.4 两点速度之差还需说明观察参考系

对点P和Q，在同一运动参考系A中定义其相对速度：

$$
{}^A\mathbf v^{P/Q}
:={}^A\mathbf v^P-{}^A\mathbf v^Q
=D_A\mathbf r_{QP}.
\tag{2-17}
$$

相减前应将两个速度表达在同一基中；相减后仍可用其他已定义坐标轴表达。这个量描述“在A中观察，两点位置差怎样变化”。它一般不等于P在某个以Q为原点的旋转参考系B中的速度，因为Q本身没有规定B的轴怎样转动。

同样，相对姿态、表压与相对误差各有自己的关系；“相对”既不统一意味着相减，也不统一意味着换坐标。


## 2.7 求导参考系与运输关系

### 2.7.1 向量导数为何依赖参考系

设B相对A的角速度为 $\,{}^A\boldsymbol\omega^B$。对同一物理向量 $\mathbf q(t)$，将它展开在B的基向量上，并对A中的变化求导：

$$
\begin{aligned}
\mathbf q&=\sum_i q_i^B\mathbf e_i^B,\\
D_A\mathbf q
&=\sum_i\dot q_i^B\mathbf e_i^B
+\sum_i q_i^B({}^A\boldsymbol\omega^B\times\mathbf e_i^B)\\
&=D_B\mathbf q+{}^A\boldsymbol\omega^B\times\mathbf q.
\end{aligned}
\tag{2-18}
$$

第一部分来自分量变化，第二部分来自基向量相对A的转动。这里讨论的是旋转参考系中的向量导数运输关系。[R13][R14]

式（2-18）中的各项都是物理向量。数值运算前应将它们表达在同一基中，不能把一项的A轴分量与另一项的B轴分量直接相加或作叉积。

### 2.7.2 对分量数组求导不自动得到指定参考下的向量导数

若已知分量数组 $[\mathbf q]_E$，则：

$$
[D_A\mathbf q]_E
=\frac{\mathrm d[\mathbf q]_E}{\mathrm dt}
+[{}^A\boldsymbol\omega^E]_E\times[\mathbf q]_E.
\tag{2-19}
$$

右侧普通导数只处理沿E轴分量的变化；E相对A转动时，还需要第二项。表达基与求导参考之间不存在相对转动，或相应叉积项确为零时，才可在该情形下省略它。

因此，“对某坐标系中的数据作差分”需要同时说明数组的表达基和想获得的物理导数。将某个三元组送入差分程序，并不能自动确定它是哪一种速度或加速度。

### 2.7.3 改变运动参考还需要平移与转动关系

由 $\mathbf r_{O_AP}=\mathbf r_{O_AO_B}+\mathbf r_{O_BP}$，应用式（2-18）：

$$
{}^A\mathbf v^P
={}^A\mathbf v^{O_B}
+{}^A\boldsymbol\omega^B\times\mathbf r_{O_BP}
+{}^B\mathbf v^P.
\tag{2-20}
$$

三项依次是B原点相对A的速度、B转动引起的携带项、P相对B的速度。若最终用E轴表达，三项均应转换为E轴分量。式（2-20）是运动关系变换，包含的信息多于式（2-16）的纯分量变换。

若比较点取 $Q=O_B$，则：

$$
{}^A\mathbf v^{P/O_B}
={}^B\mathbf v^P+
{}^A\boldsymbol\omega^B\times\mathbf r_{O_BP}.
\tag{2-21}
$$

这直接给出“在A中取两点速度之差”与“P相对旋转参考系B的速度”的区别。即使B原点不动，转动项仍可能不为零。

### 2.7.4 加速度中还会出现哪些项

令 $\,{}^A\boldsymbol\alpha^B=D_A({}^A\boldsymbol\omega^B)$。继续对式（2-20）在A中求导：

$$
\begin{aligned}
{}^A\mathbf a^P
={}&{}^A\mathbf a^{O_B}
+{}^A\boldsymbol\alpha^B\times\mathbf r_{O_BP}\\
&+{}^A\boldsymbol\omega^B\times
({}^A\boldsymbol\omega^B\times\mathbf r_{O_BP})\\
&+2\,{}^A\boldsymbol\omega^B\times{}^B\mathbf v^P
+{}^B\mathbf a^P.
\end{aligned}
\tag{2-22}
$$

其中包含原点平移加速度、角加速度项、向心项、科里奥利项和相对加速度。[R14] 该式是经典刚性参考系的运动学关系；动力学中是否可以直接采用惯性形式的牛顿方程，还需判断所用参考系及相应惯性项。

不能将式（2-22）当成“所有加速度传感器读数的变换公式”。例如加速度计测得的比力与运动学加速度之间还有重力等关系，必须先明确输入所代表的物理量。

### 2.7.5 旋转平台的反例

设A为地面参考系，B绕共同原点Q以 $1\ \mathrm{rad/s}$匀速转动，P固定在B上，距Q为1 m。取某时刻两系轴重合，P沿共同x轴，转动正方向沿共同z轴右手规定。由上式：

| 物理量，均沿A轴表达 | 数值 |
| --- | --- |
| $[{}^B\mathbf v^P]_A$ | $(0,0,0)$ m/s |
| $[{}^A\mathbf v^P]_A$ | $(0,1,0)$ m/s |
| $[{}^A\mathbf v^{P/Q}]_A$ | $(0,1,0)$ m/s |
| $[{}^B\mathbf a^P]_A$ | $(0,0,0)$ m/s² |
| $[{}^A\mathbf a^P]_A$ | $(-1,0,0)$ m/s² |

P在平台上不动，并不意味着其相对地面的速度和加速度为零。把所有结果都改用A轴表达，也不会消除这些物理关系的差别。

这一反例应作为接口测试的一部分：若程序把相对B的零速度仅作旋转就当成相对A速度，将遗漏携带运动。只有把目标、运动参考、表达基和时刻分别写清，才能判断具体数据应使用哪一个公式。


## 2.8 正负号、旋转方向与姿态约定

### 2.8.1 正方向需要连同作用对象记录

位置正方向、速度正方向、正转矩、正电流和电压正端都应明确。电流正方向与电压正端配合采用关联参考方向时，$p=vi>0$表示相应元件吸收功率；改变方向约定后，应相应解释符号。运动学中的角速度正方向按本章右手约定，并不意味着所有设备编码器默认采用同一正转方向。

左、右手坐标系之间的分量映射可能具有行列式-1，不能直接作为SO(3)中的纯旋转使用。尤其是角速度、力矩和叉积关系，混用手性时需要一致处理，不能只改一个轴符号后沿用全部右手公式。

### 2.8.2 主动转动物理对象与被动更换表达

若用A轴表达，将物理向量实际转动得到新向量，可写为 $[\mathbf q']_A=Q_A[\mathbf q]_A$；若物理向量不变，只更换表达基，则采用式（2-10）。两者可能使用相似矩阵数值，但输入输出的物理含义不同。[R10]

例如绕A的正z轴主动转90°，会把沿正x的向量转向正y。若B的轴由A的轴作同样正向转动而成，则 $R_{AB}=R_z(90^\circ)$；同一向量从A改用B轴表达应使用其转置 $R_{BA}$。因此，“转了90°”还必须说明转的是对象还是坐标轴，以及所用矩阵把哪组分量映射到哪组分量。

### 2.8.3 用矩阵定义旋转顺序

本章基本右手主动旋转矩阵按列向量定义为：

$$
\begin{aligned}
R_x(\phi)&=\begin{bmatrix}1&0&0\\0&\cos\phi&-\sin\phi\\0&\sin\phi&\cos\phi\end{bmatrix},\\
R_y(\theta)&=\begin{bmatrix}\cos\theta&0&\sin\theta\\0&1&0\\-\sin\theta&0&\cos\theta\end{bmatrix},\\
R_z(\psi)&=\begin{bmatrix}\cos\psi&-\sin\psi&0\\\sin\psi&\cos\psi&0\\0&0&1\end{bmatrix}.
\end{aligned}
\tag{2-23}
$$

角度进入三角函数前采用弧度。若姿态接口选择ZYX分解，则本章明确约定：

$$
R_{AB}=R_z(\psi)R_y(\theta)R_x(\phi).
\tag{2-24}
$$

这里 $(\phi,\theta,\psi)$通过该等式定义，$R_{AB}$仍将B分量映射到A分量。它可解释为从初始重合姿态依次绕当前z、当前y、当前x轴转动 $\psi,\theta,\phi$；若解释为依次作用于列向量的固定轴旋转，则右端因子先作用。只写“先偏航、再俯仰、后滚转”而不说明固定轴/运动轴和矩阵含义，仍会留下歧义。

矩阵通常不交换。例如 $\mathbf e_x=(1,0,0)^{\mathsf T}$，则 $R_x(\pi/2)R_y(\pi/2)\mathbf e_x=(0,1,0)^{\mathsf T}$，而 $R_y(\pi/2)R_x(\pi/2)\mathbf e_x=(0,0,-1)^{\mathsf T}$。

该三角参数化在俯仰为 $\pm\pi/2$处出现奇异，旋转矩阵本身并不因此失效。陀螺角速度分量也不能直接当作三个欧拉角的变化率，需要由相应姿态参数化建立关系。

### 2.8.4 相对姿态与角度绕回

已知A、B姿态均相对同一参考W，且矩阵都采用本章方向定义，则：

$$
R_{AB}=R_{WA}^{\mathsf T}R_{WB}.
\tag{2-25}
$$

这是B相对于A的姿态关系。一般三维姿态不能通过逐项相减欧拉角得到。对共同平面、共同零方向和正方向的单个航向角，可以采用最短有符号角差：

$$
\delta\theta=\operatorname{atan2}
\bigl(\sin(\theta_B-\theta_A),\cos(\theta_B-\theta_A)\bigr).
\tag{2-26}
$$

三角函数采用弧度，$\pm\pi$边界由接口统一约定。例如 $\theta_A=179^\circ$、$\theta_B=-179^\circ$时，普通差为-358°，绕回后的最短角差为+2°；若关注多圈累计转动，则不能丢掉圈数后使用该最短角差替代。

四元数接口还应说明分量顺序、乘法定义、变换方向和单位长度要求。不能从“四元数”这个名称推断不同程序库采用相同约定。

### 2.8.5 一个正确轴变换与一个错误简化

在同一原点、同一地点的局部水平系中，ENU分量改为NED分量可采用：

$$
R_{\mathrm{NED,ENU}}=
\begin{bmatrix}0&1&0\\1&0&0\\0&0&-1\end{bmatrix}.
$$

它同时交换东、北顺序并改变竖直正方向，行列式为+1。只将ENU的z取反而保留x、y顺序，得到的是另一组轴定义，不能称为上述NED变换。具体项目的轴向约定应按其文档确定。[R15]

## 2.9 时间原点、时钟与事件语义

### 2.9.1 时间戳与时间间隔不同

时间戳是某事件在特定时间坐标中的读数；时间间隔是两个事件之间的持续量。前者需要原点或纪元、时标、时钟来源和事件含义，后者还需合适的频率尺度。用于测量持续时间的单调时钟，与可能校时或跳变的系统时间不应混用。ROS的时钟设计也明确区分系统、稳态及可控制的仿真时间语义。[R16]

在明确适用的局部区间内，若两个时钟读数近似满足：

$$
\tau_B=\alpha\tau_A+\beta,\qquad
\Delta\tau_B=\alpha\Delta\tau_A,
\tag{2-27}
$$

则 $\beta$表示该模型下的原点偏移，$\alpha$表示读数尺度和频率比例。两边数值必须已说明单位；实际校准还应给出估计误差、有效时间段和更新方式。不同单位与不同频率误差不能只因均进入 $\alpha$就被视为同一种来源。

原点偏移在同一时钟的差分中可以相消，频率比例仍影响持续时间。漂移、重置、回绕、仿真暂停及时间跳变不一定能由一个全局恒定的 $\alpha,\beta$描述。

### 2.9.2 同一时钟也不能替代事件定义

一条图像或位置数据可能分别具有曝光开始、曝光中心、曝光结束、处理完成、发送和接收时刻。同步时钟之后，若两边使用不同事件，仍不能直接将它们当作同一状态时刻。

假设A发送时戳为12.000 s，B接收时戳为12.005 s，且此局部区间两钟同速、B比A快0.004 s，则按共同时间计算的单向传输持续时间为0.001 s。若钟差未知，直接相减无法区分钟差与传输时间。

对以0.20 m/s运动的目标，5 ms信息年龄对应1 mm的位移。这个误差不能靠把毫米换成米消除，需要时间对齐或有依据的运动预测；相关模型见第一章。

## 2.10 换算后，不确定度也应正确变换

### 2.10.1 精确尺度与零点

若随机量或不确定量的数值表达满足 $y=ax+b$，且a、b为确知常数，则：

$$
u_y=|a|u_x,\qquad P_y=a^2P_x.
\tag{2-28}
$$

其中u表示标准差或在明确不确定度模型下的标准不确定度，P表示相应方差。两种统计解释应各自说明，不能未经定义混用。

从mm换成m时，均值和标准差数值乘以 $10^{-3}$，方差数值乘以 $10^{-6}$。精确零点平移b不改变分散性；实际零点、比例或校准参数存在不确定性时，还需纳入它们的贡献。摄氏温度与开尔文之间的精确偏移本身不引入额外校准误差。

### 2.10.2 同一量的确定性坐标变换

对同一随机向量 $\mathbf x_B$及确定矩阵R、确定平移t，若 $\mathbf x_A=R\mathbf x_B+\mathbf t$，则：

$$
\boldsymbol\mu_A=R\boldsymbol\mu_B+\mathbf t,\qquad
P_A=RP_BR^{\mathsf T}.
\tag{2-29}
$$

式（2-29）对该仿射模型是精确关系；用于刚体坐标时，R应与均值使用同一方向。不能只转换均值而保留原分量顺序下的协方差，也不能给同一位移向量的均值误加位置平移。

若变换参数 $\boldsymbol\eta$也不确定，将它们与原始量组成联合输入，局部一阶传播可写为：

$$
\mathbf z=f(\mathbf x,\boldsymbol\eta),\qquad
P_z\approx J P_{(\mathbf x,\boldsymbol\eta)}J^{\mathsf T},
\quad
J=\begin{bmatrix}\partial f/\partial\mathbf x&
\partial f/\partial\boldsymbol\eta\end{bmatrix}.
\tag{2-30}
$$

联合协方差应包含必要的交叉项，不能自动假定原始测量与标定参数独立。该式需要局部线性近似适用，非线性和大姿态不确定性应另行检查。[R17] 正确换算保持已有信息的一致表达，不会凭空改善原始测量能力。


## 2.11 完整换算样例：从传感器数据到设备坐标

### 2.11.1 先给出数据定义

设A为设备基坐标系，B为安装测量坐标系。两者为右手正交系，当前时刻B相对A的几何关系已确定。以下矩阵和测量值均为教学假设：

$$
R_{AB}=\begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix},\qquad
\mathbf t_{AB}=\begin{bmatrix}1\\2\\0\end{bmatrix}\mathrm m,\qquad
\mathbf p_P^B=\begin{bmatrix}1000\\0\\0\end{bmatrix}\mathrm{mm}.
\tag{2-31}
$$

输入描述同一物理点P在采样时刻 $t_m$相对 $O_B$的位置，沿B轴表达。B的轴由此例明确给定，不从“传感器”名称推断。变换在同一时刻有效，当前计算暂把其参数视为确知值。

### 2.11.2 分别完成尺度与几何关系变换

先将输入坐标数值从mm转成m，得到 $(1,0,0)^{\mathsf T}$ m。再应用式（2-12），输出：

$$
\mathbf p_P^A
=R_{AB}\begin{bmatrix}1\\0\\0\end{bmatrix}\mathrm m
+\begin{bmatrix}1\\2\\0\end{bmatrix}\mathrm m
=\begin{bmatrix}1\\3\\0\end{bmatrix}\mathrm m.
$$

输出仍然描述点P在 $t_m$的位置，只改变位置参考和分量表达。若下游要的是另一个时刻或另一个点，还需要相应运动或几何信息。

若输入实际是位移向量 $[\mathbf r_{PQ}]_B=(1000,0,0)^{\mathsf T}$ mm，则对应输出是 $(0,1,0)^{\mathsf T}$ m，不能再加 $\mathbf t_{AB}$。若另有已知两点位移 $[\mathbf r_{PQ}]_B=(0.2,0,0)^{\mathsf T}$ m，则Q的位置为 $(1,3.2,0)^{\mathsf T}$ m。这是改变测点，必须明确附加几何关系。

### 2.11.3 让不确定度与均值使用相同约定

假设输入位置的标准不确定度分量为10、20、30 mm，分量不相关，对应输入协方差为 $\operatorname{diag}(100,400,900)$ mm²。单位和坐标变换给出：

$$
\begin{aligned}
P_{B,\mathrm m}&=10^{-6}\operatorname{diag}(100,400,900)\,\mathrm m^2,\\
P_{A,\mathrm m}&=R_{AB}P_{B,\mathrm m}R_{AB}^{\mathsf T}\\
&=\operatorname{diag}(4\times10^{-4},10^{-4},9\times10^{-4})\,\mathrm m^2.
\end{aligned}
\tag{2-32}
$$

输出沿A轴的标准不确定度分量为0.02、0.01、0.03 m。若只将输入协方差乘以 $10^{-3}$，或者不交换旋转后对应的轴向，将与位置输出不一致。实际R、t存在标定不确定性时，应继续使用式（2-30）等适当方法评估，不能把此处的确知假设直接照搬。

### 2.11.4 用独立样例检查转换

至少检查以下内容：

- **原点：** B原点在A中的坐标应等于 $\mathbf t_{AB}$。
- **已知正方向：** B的正x轴在本例应映射到A的正y方向。
- **尺度：** 1000 mm位移应保持为1 m的同一物理长度。
- **刚体不变量：** 同一位移的长度、两点间距离及向量夹角在对应刚体表达变换中保持。
- **逆变换：** 采用 $R_{BA}=R_{AB}^{\mathsf T}$和对应逆平移，能够恢复原输入。
- **不确定度：** 均值和协方差的单位、轴序和变换方向相同。
- **时间与对象：** 转换前后对应时刻和物理点没有被悄然替换。

一对互为逆的错误矩阵也可能通过往返检查。因此，逆变换测试应与独立的原点、方向及物理量样例共同使用；点坐标的模长不必在原点改变后保持，不能误用位移不变量去判断点坐标。

## 2.12 物理量与基准字典

### 2.12.1 字典记录什么

字典的任务是使另一位工程师能够依据定义正确使用数据。字段可按对象类型裁剪，不适用项应明确标为不适用，不强行为纯标量添加空间坐标系。

| 字段组 | 必需说明 |
| --- | --- |
| 标识与物理定义 | 名称、定义式、量的种类、所代表的对象或物理点 |
| 数学类型 | 标量、向量、张量、姿态、状态码等；数组长度和分量顺序 |
| 数值与单位 | 单位、比例、偏移、有效范围和特殊值含义 |
| 参考关系 | 参考点、机械基准、电气参考端或其他比较对象 |
| 运动与求导参考 | 运动相对哪个参考系定义，涉及导数时在哪个参考系求导 |
| 表达坐标系 | 轴向、手性、分量表达基及其定义入口 |
| 正负号与旋转 | 正方向、输入输出方向、角度与姿态约定 |
| 时间 | 时钟/时标、原点、事件、单位、对应时刻和同步状态 |
| 统计口径 | 窗口、采样/带宽、平均/峰值/RMS、是否包含直流 |
| 不确定度 | 标准差或协方差含义、单位、轴序和交叉项 |
| 有效性 | 就绪、无效、丢失、过期、未同步等状态的区别 |
| 换算与版本 | 方程、参数来源、适用条件、标定/接口版本及检查样例 |

特别注意：运动参考、分量表达基和比对测量的参考标准是三类信息，不能全部塞进一个未定义的“reference”字段。

### 2.12.2 三种数据条目的填写示例

| 条目 | 定义与参考 | 表达、时间和检查 |
| --- | --- | --- |
| 点P位置 | 从 $O_B$指向P的位置坐标，禁止默认为作用点Q | B轴，mm，采样事件 $t_m$；按式（2-31）应得到A轴位置 $(1,3,0)$ m |
| 点P相对B的速度 | $\,{}^B\mathbf v^P=D_B\mathbf r_{O_BP}$ | 可沿A轴表达，m/s；旋转平台中该量可以为0，而相对A速度非0 |
| A端相对G的电压 | 规定 $V_{AG}$及两端，不把机壳自动视为G | V；说明瞬时/平均/RMS、窗口、直流与交流模式 |

字典应与接口实现、图纸和数据记录保持一致。只写“float[3]，单位m/s，frame=B”仍不足以确定该速度相对谁、沿谁表达、对应哪个点与时刻。

### 2.12.3 最小交付与检查

本章配套提供[物理量与基准字典模板](https://github.com/voilalz/the-art-of-engineering/blob/main/templates/physical-quantity-reference-dictionary.md)，可以为每个关键数据条目复制填写。

交付时应同时给出至少一个正常值、一个正方向或已知基准值、一个无效状态样例，以及必要的逆变换或复核结果。参数、基准或时钟定义变化后，需要更新对应版本及已验证样例。

## 2.13 常见混淆与审查问题

| 混淆 | 正确的检查方向 |
| --- | --- |
| 单位相同就能直接比较 | 继续核对量的种类、对象、参考、时刻和统计定义 |
| 换成SI单位就完成接口统一 | 单位只解决部分数值表达，基准与语义仍需明确 |
| 点坐标和位移都加原点平移 | 根据数据的几何类型选择点或向量规则 |
| 用一个frame字段同时表示运动参考和表达基 | 分别记录研究对象、运动参考、表达基与时刻 |
| 两点速度相减等于在以其中一点为原点的转动系中速度 | 使用式（2-21）检查转动项 |
| 对表达分量求导就是指定参考下的向量导数 | 检查表达基是否转动并使用运输关系 |
| 所有“相对”都可以做数值相减 | 根据误差、压力、姿态或运动的具体定义处理 |
| 峰值除以 $\sqrt2$总能得到RMS | 先核对波形、直流、窗口与带宽 |
| 时间单位相同就能相减得到时延 | 核对时钟来源、尺度、原点和事件 |
| 只换均值，不换方差与协方差 | 按同一尺度和轴向传播不确定度 |
| 变换往返一致就证明方向正确 | 再用独立原点、正方向和物理不变量检查 |

审查任一关键数据，应能回答：它描述什么对象或点；相对于谁定义；在哪个参考系求导；沿哪组轴表达；采用什么单位和正方向；对应哪个事件、时刻或窗口；无效状态是什么；变换依据和版本在哪里。

本章的完成标准，是另一支团队不依赖口头猜测，就能重现数据的物理含义、正确换算并解释其使用限制。
