## 已填写教学样例：同一点的位置表达转换

以下为教学假设，不作为真实产品的性能要求。A为设备基坐标系，B为安装测量坐标系，均为右手正交系。输入和变换对应同一采样时刻；本例暂把变换参数视为确知值。

| 字段 | 样例内容 |
| --- | --- |
| 数据标识 | position_P_in_B |
| 物理定义 | $\mathbf p_P^B=[\mathbf r_{O_BP}]_B$，从B原点指向点P的位置坐标 |
| 对象 | 同一物理点P，输出不得自动替换为作用点Q |
| 数学类型 | 3分量列向量，顺序x、y、z |
| 输入单位与数值 | mm；$(1000,0,0)^{\mathsf T}$ |
| 参考点与表达基 | 起点 $O_B$；沿B轴表达 |
| 运动/求导参考 | 此条为位置，不是速度或向量导数；无独立求导操作 |
| 正方向与轴关系 | B正x映射到A正y，B正y映射到A负x，B正z映射到A正z |
| 时间 | 共同单调时钟CLOCK-A，秒；样例 $t_m=12$ s，表示采样事件 |
| 统计口径 | 此次位置估计；不作时间平均或RMS |
| 不确定度假设 | 沿B轴标准不确定度10、20、30 mm，三分量不相关 |
| 输入协方差 | $\operatorname{diag}(100,400,900)\,\mathrm{mm}^2$ |
| 目标表达 | 同一时刻、同一点P，相对 $O_A$且沿A轴的位置，单位m |
| 参数有效性 | 仅为此教学计算给定；真实系统需给出标定版本和有效条件 |

转换定义为：

$$
R_{AB}=
\begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix},
\quad
\mathbf t_{AB}=
\begin{bmatrix}1\\2\\0\end{bmatrix}\mathrm m,
\quad
\mathbf p_P^A=R_{AB}\mathbf p_P^B+\mathbf t_{AB},
$$

其中应用最后一式前，位置数值统一为米。结果为：

$$
\mathbf p_P^A=\begin{bmatrix}1\\3\\0\end{bmatrix}\mathrm m,\qquad
P_A=\operatorname{diag}(4\times10^{-4},10^{-4},9\times10^{-4})\,\mathrm m^2.
$$

在同样参数下，位移向量 $(1000,0,0)^{\mathsf T}$ mm转换后为 $(0,1,0)^{\mathsf T}$ m，使用旋转而不加原点平移。若实际变换含不确定性，应继续传播变换参数及其相关性。

| 检查 | 输入或条件 | 预期结果 | 实际结果与证据 |
| --- | --- | --- | --- |

| 原点 | 点恰在 $O_B$，B坐标为0 | A坐标为 $(1,2,0)^{\mathsf T}$ m | 待填写 |
